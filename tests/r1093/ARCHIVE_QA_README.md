# Native archive QA

`archive-browser.js` contains 13 native groups and runs the complete Classic/Feyz app in disposable Chromium with native IndexedDB. It uses the original `temel` category: four WebM files, 187655 bytes, selected from the unchanged 291-record manifest. It does not claim a download of all 291 files.

The suite checks partial download/reload/missing-only resume, actual staged-blob rehash and corruption repair, explicit cancellation, a labelled native stage-store quota failure, corrupted network-byte rejection, stale preview after a second app tab writes the generic bank, simultaneous native write transactions using one expected bank revision, trusted UI review/commit, category merge/replace, disabled playback after commit, protected-category privacy and TR/EN 320/390 px layout. A labelled synthetic old generic bank and personal-recording sentinel prove that preparation and failures preserve published recordings, preferences and counters. Network and storage fault injections are listed in the JSON report. The concurrent CAS case labels its temporary maintenance-admission seam and a settlement barrier applied only after the real native final metadata digest has been computed. It keeps the real core validation and native IndexedDB transactions, requires both contenders to reach a write transaction, and verifies exactly one complete winning bank after a fresh reload.

Both suites apply their exact audio faults through local native HTTP adapters while leaving the shared browser fixture unchanged. Their temporary server-constructor wrappers are restored before app testing. Interruption sends one original byte with the full original Content-Length before closing the response. The main suite also holds one exact request for production cancellation and returns one same-length response with its last byte flipped. Reports retain request identities, phases, response receipts and original/sent byte digests. Ordinary local HTTP is not intercepted by Playwright after fixture startup; external HTTPS blocking uses a narrow route. Expected request failures require exact injected identities and bounded phases; every unplanned archive failure remains blocking.

`archive-worker-browser.js` contains 6 native groups and creates a separate context with a real installed service worker. It checks the current complete graph and real archive capability receipt, interrupted exact-byte staging, cold reload/resume, empty optional-archive entries across **all** CacheStorage caches, explicit cancellation and a cold offline required graph with failing marked optional requests. It never substitutes a fake worker or STATUS receipt. Its network-failure and offline socket gates are explicit in the report. Intentional failures use exact native request IDs and bounded probe phases. Ordinary same-origin traffic is not intercepted. Worker-owned `ERR_ABORTED` observations during boot/reload are reported separately only when direct current runtime-cache or optional-art-cache bytes match the pinned local, served and inventory SHA-256 values. Required runtime, the four exact release metadata artifacts and optional artwork remain distinct buckets. Deliberate cold-offline worker network denials form a separate bucket restricted to the exact reload phase, shell/marker or inventory artwork, the active offline/socket gates and fresh cached-byte proof; `ERR_EMPTY_RESPONSE` also needs the actual denied server path. That evidence proves artifact readiness, not successful completion or a known cause for those aborted requests; unverified, unknown, page-owned and unplanned archive failures block the suite.

Both scripts accept the repository root and an absolute output JSON path, record source/test hashes and close their browser contexts and HTTP fixture before the Node process exits. Run only after the app, SRI and service-worker graph are finalized; production mutations during a run invalidate its evidence.

```sh
NODE_PATH=/opt/codex/runtimes/codex-primary-runtime/dependencies/node/node_modules CHROMIUM_PATH=/tmp/sukun-browser/chromium node tests/r1093/archive-browser.js /absolute/repository /absolute/qa/archive/native.json
NODE_PATH=/opt/codex/runtimes/codex-primary-runtime/dependencies/node/node_modules CHROMIUM_PATH=/tmp/sukun-browser/chromium node tests/r1093/archive-worker-browser.js /absolute/repository /absolute/qa/archive-worker/native.json
```

These suites do not measure physical Android locking, microphone capture, audible quality, mobile bandwidth or device quota. Existing worker-controlled tests cover additional recovery-pin and request-validation cases.
