# TTS name vocatives

Only TTS text for Esmâü’l-Hüsnâ and Berhetiyye names receives a missing `Yâ`
(Latin) or `يَا` (Arabic). Source catalog and recording bytes/keys remain
unchanged. The name's explicit category or exact catalog identity determines
scope; a prayer dialog cannot inherit the selected name behind it.

Existing Latin/Arabic vocatives are compared without combining marks or
tatweel to avoid duplication while preserving the original spelling.
Meanings, complete tawhid formulas and all other reading categories retain
their original text. Favourite entries resolve their source category.

The controlled source fixture exercises the formatter and the shipping
policy/resolver dispatch. `tts-name-browser.cjs` separately observes utterance
text through the complete application and verifies that a real native
personal recording still takes priority. The browser speech callbacks are a
controlled fixture seam; no claim is made about a physical device voice's
pronunciation, Samsung audio output or lock-screen policy.
