# r1051 dashboard error presentation

```sh
node tests/r1051/dashboard-error-state.cjs
```

Executes the shipped dashboard function, visible-only phase-filtered listener,
shared I18N writer and shipped TR/EN mappings with controlled DOM and read-only
canonical/lifecycle inputs. An ERROR session takes priority over the automatic
intent's lifecycle playing label. Retry, finish, language changes and normal
ambient/frequency/lifecycle labels retain their presentation. Hidden session
events do no dashboard work; 3,600 count-only publications cause no additional
dashboard or canonical reads. The fixture rejects audio, transport, lifecycle,
counter, storage and timer commands. Physical browser audio is not measured.
