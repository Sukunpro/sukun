# SÜKÛN r993 yükleme ve kullanım

ZIP'i aç. GITHUB_DOSYA_LISTESI_r993.txt içindeki kök dosyalarını depo köküne ve assets klasörünü aynı alt yollarıyla yükle; aynı adlı dosyaları değiştir, tek commit kullan. ZIP'i tek başına depoya koymak uygulamayı güncellemez. integration ve raporların yayına yüklenmesi zorunlu değildir. Kişisel kayıtları veya tarayıcı depolamasını silme. Uygulama ve servis çalışanı birlikte r993 göstermeli. Güncellemeyi çevrimiçi açıp tamamlanmasını bekle.

## Kullanım

- Ana sayfada set özeti: Başlat / Set ayarları / Detaylar / ×. Kart zikir sekmesinde ve tam ekran çarkta görünmez. Set seçimi ve kayıtlarını silmeden kapatılabilir.
- Tekke girişinde amaç seç: Zikir ve nefes, Tefekkür seti veya Sessiz tefekkür. Yarım kalan set varsa Devam et / Baştan başlat açık kullanıcı seçimidir.
- İlk giriş → Tefekkür seti → Seans hazırlığı: Çevrimdışı hazırla veya Kontrol et. Eksik TTS adımlarını kendi sesinle tamamlamak için Mihrap → Kayıtlar → Kayıt rehberini aç. Cihaz sesini internet kapalıyken ayrıca dene.
- Kayıt rehberi: Metni oku ve Kaydet; Durdur, Dinle, istersen Sessizlikleri kes → Önizle, ardından Bu kaydı kullan. Özgün ses onay olmadan değiştirilmez. Eksik adıma git kalan kayıtları bulur. Rehberden sonra seans için ayrıca Devam et gerekir.
- Set çalarken Önceki / Tekrar dinle / Sonraki. Sonraki mevcut adımı atlar; tamamlanmış saymaz. Duraklatılmış set adım değişince kendi kendine başlamaz.
- Mihrap → Seans → Kişisel Tekke düzenleri: ad verip sakla; sonradan seç ve Uygula. Önce aktif seansı bitir. Tempo değişmez, ses başlamaz.
- Seans sonunda isteğe bağlı notu Kaydet. Notlar Mihrap → Seans → Tefekkür notlarım'dadır. Sessizlikte kal sessiz amacı, Seansı bitir kapanışı seçer.
- Set oynatımında Açıklama ve kaynak metni isteğe bağlıdır; kaynak bağlantısı internet ister.

## Telefonda kabul kontrolü

1. Ana sayfa, Zikir sekmesi ve tam ekran çark arasında geç. Set kartı çarka/sayaç başlığına binmemeli; gizlenmesi set seçim ve kayıtlarını silmemeli. Ana sayfada Detaylar/× çalışmalı.
2. Tam kayıtlı ve karışık TTS setini ayrı ayrı başlat. Duraklat/Devam et, adım değişimi, tekrar dinleme, Mihrap aç/kapat ve SÜKÛN'a dön/geri gel akışını dene.
3. Set sürerken uygulamayı kapatıp tekrar aç: ses otomatik başlamamalı; Devam et kayıtlı son adımı başından okumalı. Bitir veya × sonrası gereksiz kurtarma kartı kalmamalı.
4. Yeni ses kaydet; onaydan önce eski kayıt kullanılmalı. İzin reddi, kesme önizlemesi, özgün kaydı getir ve yeniden onayla akışını dene. Kayıt alınırken yeni seans başlamamalı.
5. Önce çevrimdışı hazırlığı tamamla, interneti kapat, tam kayıtlı seti ve varsa cihaz sesini ayrı ayrı dene. Eksik görsel/kabuk veya internet gerektiren TTS hazır diye gösterilmemeli.
6. Uzun kullanım, telefon kilidi, kilitten dönüş, eski Xiaomi ve dar ekran/Türkçe/İngilizce kaydırma-dokunma kontrolü yap. Bu fiziksel kontroller bu ortamda çalıştırılmadı.

Güncel ayrıntılar RAPOR_r993.md ve DOGRULAMA_r993.json içindedir.
