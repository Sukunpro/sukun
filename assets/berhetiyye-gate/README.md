# Berhetiyye gate · r1080

The gate is a decorative, symbolic entrance to the existing Berhetiyye UI. Its guardian, concealed mechanism and Istanbul-inspired setting are fictional art direction, not a historical or religious authenticity claim.

- `portal-r1080.js/css`: independent dialog and motion state machine; no entitlement is stored by the presentation.
- `access-r1080.js`: existing configured device privacy PIN, or an explicitly configured authoritative HTTPS provider. An unconfigured first password is never enrolled by the gate.
- `entry-r1080.js/css`: one card in Readings, hidden in contemplation.
- `audio-r1080.js`: independently owned procedural wooden, mechanical, airy and ney-like effects, enabled by touch. No copyrighted music or recitation samples are used for these effects.
- Six WebP assets are optimized copies of generated portal/guardian/wheel art and the application's palace artwork.
- `invitation-tr.mp3`: generated with Higgsfield Seed Audio using the user-selected preset voice. Text: “Gel, gel… Hoş geldin. Sarayın kapısı sana açık.” 6.84 seconds (latest selected voice). This local Turkish invitation is played only by the explicit listen control, independently of the app's speech-synthesis queue.

Opening the threshold does not select or play a dhikr. Only **Enter the palace** calls the existing session selection authority. **Lock the door and leave** preserves the device password and parks private queue entries; it does not erase an access right. Optional provider deployment requirements and limitations are in `integration/berhet-access/README.md`. No remote membership server is configured in the default release.
