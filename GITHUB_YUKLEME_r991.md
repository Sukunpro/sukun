# SÜKÛN r991 yükleme

ZIP’i aç. GITHUB_DOSYA_LISTESI_r991.txt içindeki kök dosyalarını depo köküne, assets klasörünü aynı alt yollarıyla yükle; aynı adlı dosyaları değiştir ve tek commit kullan. ZIP’i tek başına depoya koymak uygulamayı güncellemez. integration ve raporları yayına yüklemek zorunlu değildir. Kişisel kayıtları veya tarayıcı depolamasını silme.

Uygulama ve servis çalışanı birlikte r991 göstermeli. Güncellemeyi çevrimiçi açıp tamamlanmasını bekle.

1. Tekke’nin ilk giriş ayarlarında Tefekkür Seti bölümünü aç. Seti seç ve kartı göster/gizle kutusunu değiştir. Göster seçimi tek başına ses başlatmamalı.
2. Kartın sağ üstündeki × ile kapat. Ana sayfa kartı da gizlenmeli. Sayfayı kapatıp açınca kapalı kalmalı. Seçim ve kayıtların korunmalı.
3. Tekke ayrı zikir/nefes seansı sürerken boştaki set kartını kapat. Zikir/nefes seansı devam etmeli.
4. Mihrap → Kendi Sesinle Anlatıcı içinden kartı yeniden göster. İlk girişteki tercih de eşleşmeli. Başlatınca set kendi kayıtlarını, eksik adımda cihaz sesini sırasıyla okumalı.
5. Set oynarken, duraklatılmışken ve hazırlanırken × ile kapatıp bekle. Set yeniden ses vermemeli. Başlat dediğinde kart tekrar görünmeli.
6. Kart kapalıyken başka set seç. Seçim saklanmalı, kart kapalı kalmalı. Devam eden sette yeni seçim mevcut akışın adını veya sırasını değiştirmemeli.
7. İngilizce dilde × açıklamasını ve ilk ayarları kontrol et. Güncelleme tamamlandıktan sonra çevrimdışı açıp tercihini ve kayıtlarını kontrol et. Fiziksel telefon/kilit ekranı testi bu ortamda yapılmadı.
