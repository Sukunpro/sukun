# r1008 yükleme

ZIP'i çıkar. `GITHUB_DOSYA_LISTESI_r1008.txt` içindeki dosyaları mevcut GitHub Pages klasörüne aynı yollarla yükle: `index.html`, `nero.html`, `sw.js`, manifest/sürüm dosyaları ve `assets` klasörünün tamamı birlikte güncellenmeli. ZIP dosyasını tek başına siteye koymak uygulamayı güncellemez.

Yayın hazır olduğunda uygulamanın güncelleme kontrolünü kullan. Ekrandaki uygulama ve SW sürümü r1008 olmalı. Kişisel kayıtları, ilerlemeyi veya site verilerini temizleme.

`tests_r1008`, doğrulama raporları ve bu yönergeler inceleme içindir; çalışma için gerekli 255 dosya ayrı listelenmiştir. Paket tüm görsel varlıkları içerir. Ayrıntılar `RAPOR_r1008.md` dosyasındadır.
