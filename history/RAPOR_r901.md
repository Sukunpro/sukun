# SÜKÛN r901

- 99 Esmâ ve 28 Kasem-i Berhetiyye kompakt isim şeritleri yatay swipe olarak korunur.
- Berhetiyye seyir kontrolü tek toggle yerine açık durum otoritesine ayrıldı: Başlat / Duraklat / Sürdür.
- Önceki İsim, Sonraki İsim, Bu İsmi Baştan, Bitir ve Tüm Seyri Baştan doğrudan Berhetiyye API durumuyla çalışmaya devam eder.
- Çift transport tetiklenmesini önlemek için 28 modunda eski ortak transport düğmesi gizlenir.
- r900 kodunun kapanış HTML etiketinden sonra kalması temizlendi; runtime katmanları body içine alındı.
- Uygulama/SW build otoritesi r901'e yükseltildi.
